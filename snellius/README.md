
Login to snellius with the username you got (5th of May) in your UvA email from 'no-reply@surf.nl' with:

```
ssh <username>@snellius.surf.nl
```

After each login load these modules for GPU usage:

```
module load 2025
module load CUDA/12.9.1
```

Get the files in this git repo on snellius with:

```
git clone https://github.com/bterwijn/GPU_Programming.git
```

Go the snellius subdirectory in this repo:

```
cd GPU_Programming/snellius/
ls
```

and continue on GitHub by clicking and reading the subdirectories to run the examples.
